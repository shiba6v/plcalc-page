# Photo Lock Calculator — official website

Public website: https://shiba6v.github.io/plcalc-page/

This repository contains only the multilingual promotional website and public app screenshots. The application source code and backend are maintained separately.

## Edit and publish

- Edit translations in `content.json` and layout in `build.py` or `site.css`.
- Run `python3 build.py` to regenerate the 25 static language pages and `sitemap.xml`.
- Push to `main`. GitHub Pages serves the repository root.
- English is at the root. Other languages use their language code, for example `/ja/`, `/de/` and `/zh-Hant/`.

Store names checked on 2026-10-24: **Photo Lock Calculator 〜秘密の写真庫〜** in Japan, **Photo Lock Calculator** elsewhere. The home-screen abbreviation is **plcalc**. Screenshots use demonstration files.

The support page, privacy policy and terms remain on the app's server. They are linked, not duplicated here. This website does not embed analytics, collect form submissions, or load third-party fonts or scripts. Links to Apple and to the app server open those services.
